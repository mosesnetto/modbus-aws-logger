# Roadmap

This roadmap describes intended engineering work, not guarantees or customer
commitments.

## Unreleased

- Optional SMTP daily summary reports
- SMTP test command and local runtime state
- Raspberry Pi 5 edge deployment guide with Tailscale, xrdp, and Flask

## 0.1.0 — Private preview

- Secure environment configuration
- Modbus TCP holding-register reads
- AWS IoT MQTT/TLS publishing
- Reconnect handling
- Offline validation mode
- Safe demo payload mode
- Unit-test and CI baseline

## 0.2.0 — Developer experience

- Modbus simulator mode
- Sanitized demo payload
- Payload schema version field
- Structured JSON logging with rotation
- Configuration validation command with clearer errors

## 0.3.0 — Operations

- Health/readiness status
- Connection and publish metrics
- Docker image
- systemd and Windows service examples
- Configurable backoff and dead-letter handling

## 1.0 candidate — Public release

- License review
- Security review
- Installation and commissioning guide
- Compatibility matrix
- Release notes and migration policy
- Public documentation and demo environment
